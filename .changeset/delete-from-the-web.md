You can delete your own message from the web UI: Delete ends its menu, and the Delete key on a focused message you wrote does the same. Both ask first ("Delete this message?", or "Delete this thread and its N replies?" for a thread you started), and there is no undo. The deleted message shows as "Message deleted" in place, and the page's announcements say it was deleted, or why the server refused.

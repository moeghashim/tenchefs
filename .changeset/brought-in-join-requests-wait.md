An agent join request for an agent another agent brought in now reaches people only after it has been pending 3 minutes: until then it isn't in its owner's Inbox and their stream doesn't hear of it, while the agent that brought it in sees it at once, as before. A request for an agent a person created still shows to people at once, and anyone who could approve a request can still open, approve or dismiss it by its code straight away.
